Welcome

  

    
Compose a Discord message properly - markdown, embeds, polls, timestamps -
      see it exactly as Discord will render it, then send it through a webhook. No Discord account,
      no bot and no sign-in.

    
    
      
  1. Add a webhook. In Discord: Server settings, Integrations, Webhooks, then copy
        the URL. Paste it into the Webhook card at the top of the page.
    2. 
      
  2. Write your message. The preview on the right updates as you type, and the JSON tab
        shows the exact payload that will be sent.
    3. 
      
  3. Send it. Sent messages are remembered, so you can edit or delete them afterwards.
    4.
